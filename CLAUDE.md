# FinSight AI project instructions

- Build an original financial intelligence product; do not copy third-party proprietary algorithms or content.
- Treat all bundled market examples as illustrative demo data. Never label them live, exchange-authoritative, or historical market data.
- Keep quantitative logic deterministic, validated, and covered by tests.
- Do not claim deployment, provider integration, or test success without verification.
- Keep API keys out of source control and frontend bundles.
- Use the FastAPI API under `/api/v1` for application data and keep frontend API configuration in environment variables.
- Update `docs/progress.md` when a meaningful milestone changes; call out incomplete work and external configuration.
- Prefer accessible, responsive interfaces and explain unavailable features rather than presenting dead controls.
